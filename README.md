🌟 HNG Internship Stage 0 Task: Profile Card 

A clean, responsive personal profile card built with HTML5, CSS3, and a touch of JavaScript.
This project demonstrates structured frontend design, semantic HTML, and adaptive CSS styling across multiple screen sizes.

🧠 Overview

This profile card displays essential personal details — including name, bio, skills, hobbies, dislikes, and social links — in a modern, minimal, and accessible layout.
The design adapts smoothly from mobile to ultra-wide desktops, ensuring excellent readability and aesthetic consistency.

🚀 Features

✅ Semantic HTML5 structure — accessible and SEO-friendly

💻 Fully responsive — optimized for mobile, tablet, and desktop

🎨 Elegant transitions & typography

🌈 Industry-accurate tech colors (React, TypeScript, Next.js, Node.js)

🕒 Dynamic time display (via JavaScript)

🔗 Interactive social media icons with hover effects

⚙️ Media queries for all major breakpoints, including 1440px

🧱 Layout Principles

Flexbox for card alignment

CSS Grid for hobbies/dislikes section

Fluid scaling using rem units (1rem = 10px)

Hover transitions for interaction feedback

📱 Responsive Breakpoints
Breakpoint	Query	Layout Behavior
≥1440px	@media (min-width: 1440px)	Expands grid, increases spacing & font size
≤836px	@media (max-width: 836px)	Adjusts section widths for tablets
≤779px	@media (max-width: 779px)	Switches to vertical stacking
≤611px	@media (max-width: 611px)	Stacks header, enlarges avatar
≤361px	@media (max-width: 361px)	Shrinks text for small devices
⚙️ How to Run the Project Locally

Clone the repository

git clone https://github.com/<your-username>/profile-card.git


(Replace <your-username> with your actual GitHub username.)

Navigate into the project directory

cd profile-card


Open the project

Option 1: Open directly in your browser:

open index.html


(On Windows: start index.html, on Linux: xdg-open index.html)

Option 2: Use a local development server for live preview (recommended):

npx live-server


or

npx serve


View the project

The profile card should open in your browser at:

http://localhost:8080/


or a similar port (depending on your local setup).

🧪 Testing

Open DevTools → Responsive Mode.

Simulate multiple devices to ensure layout adapts correctly.

Check hover transitions, bio readability, and spacing at each breakpoint.
